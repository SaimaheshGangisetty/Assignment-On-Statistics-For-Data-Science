# 📊 Statistics – Module 5 Project

## 📌 Project Overview

This project is a collection of **80 questions covering fundamental and intermediate concepts in Statistics, Probability, Linear Algebra, and Calculus**.

The assignment focuses on understanding statistical concepts and their applications in areas such as **data analysis, machine learning, probability, statistical inference, and hypothesis testing**.

The project includes both conceptual questions and numerical/problem-solving questions.

---

## 🎯 Objectives

The main objectives of this project are:

* Understand fundamental concepts of statistics and probability.
* Learn the basics of vectors and matrices.
* Understand derivatives, gradients, and their applications in machine learning.
* Study probability distributions and random variables.
* Understand sampling and statistical inference.
* Learn confidence intervals and hypothesis testing.
* Understand correlation, covariance, and causation.
* Study statistical tests such as **t-test, Chi-Square test, and ANOVA**.
* Apply statistical concepts to real-world examples and experiments.

---

## 📚 Topics Covered

### 1. 🔢 Vectors and Linear Algebra

The project begins with fundamental linear algebra concepts:

* Vectors
* Scalars
* Vector operations
* Scalar multiplication
* Magnitude of vectors
* Direction of vectors
* Square and rectangular matrices
* Basis
* Linear transformations
* Eigenvectors

These concepts provide mathematical foundations used in statistics, data science, and machine learning.

---

### 2. 📈 Calculus and Machine Learning

The project covers calculus concepts and their applications in machine learning:

* Derivatives
* Partial derivatives
* Gradients
* Backpropagation
* Optimization algorithms

The questions explore how derivatives and gradients are used when training machine learning models.

---

### 3. 🎲 Probability Theory

The probability section covers:

* Probability theory
* Components of probability
* Conditional probability
* Bayes' theorem
* Random variables
* Law of Large Numbers
* Central Limit Theorem
* Discrete probability distributions
* Continuous probability distributions

These concepts form the foundation for statistical analysis and inference.

---

### 4. 📊 Descriptive Statistics

The project covers techniques used to summarize and understand data:

* Measures of central tendency
* Mean
* Median
* Mode
* Percentiles
* Quartiles
* Outliers
* Skewness
* Kurtosis
* Bessel's correction

Questions also cover the difference between descriptive and inferential statistics.

---

### 5. 🔗 Joint Probability and Correlation

The project explores relationships between random variables through:

* Joint probability distributions
* Marginal probability distributions
* Covariance
* Correlation coefficient
* Independence of random variables
* Correlation vs. causation

These concepts help understand relationships between variables in statistical datasets.

---

### 6. 🔬 Sampling and Statistical Inference

The assignment covers important concepts related to statistical inference:

* Sampling
* Sampling methods
* Sampling error
* Parameter estimation
* Hypothesis testing
* Central Limit Theorem
* Degrees of freedom

The project also examines how sample information can be used to understand a larger population.

---

### 7. 📐 Confidence Intervals

The project covers:

* Confidence intervals
* Confidence levels
* Margin of error
* Factors affecting interval width
* Effect of sample size
* Effect of confidence level
* Interpretation of confidence intervals

It also examines whether confidence intervals can be used to make statements about individual members of a population.

---

### 8. 🧪 Hypothesis Testing

The assignment discusses:

* Null hypothesis
* Alternative hypothesis
* p-value
* One-tailed tests
* Two-tailed tests
* Type I error
* Type II error
* Statistical power
* Non-parametric hypothesis testing

Hypothesis testing is used to determine whether observed evidence provides sufficient statistical evidence against a null hypothesis.

---

### 9. 🧮 Statistical Tests

The project introduces several commonly used statistical tests:

#### Chi-Square Test

Used for analyzing categorical data and testing relationships or goodness of fit.

#### t-Test

Used to compare means, particularly when population variance is unknown.

#### ANOVA

Used to analyze differences among multiple group means.

These tests are included in the final section of the assignment.

---

### 10. 📢 A/B Testing

The project also covers the application of hypothesis testing in **A/B testing for marketing campaigns**.

A/B testing can be used to compare two versions of a campaign or experience and statistically evaluate whether their observed performance differs.

---

## 📝 Numerical Problems

The assignment includes numerical questions involving concepts such as:

* Z-scores
* Probability
* Dice experiments
* Confidence intervals
* Sampling
* Hypothesis testing

For example, one question provides a test mean of **160**, standard deviation of **15**, and a z-score of **1.20**, and asks for the corresponding test score.

Another question involves calculating the probability of observing at least one event over multiple time intervals.
